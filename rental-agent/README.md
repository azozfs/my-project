# وكيل واتساب — قسم التأجير (أطوار)

وكيل ذكي يرد على رقم واتساب قسم التأجير على مدار الساعة، ويشتغل بـ Claude.

## وش يسوي

| العميل | الوكيل |
|---|---|
| يبي يستأجر | يسأله عن الحي والغرف والميزانية، ويبحث في الوحدات **الشاغرة** من كشف الإكسل، ويعرض أنسبها. إذا عجبته وحدة يسجّله «عميل مهتم» لموظف التأجير. |
| مستأجر عنده عطل أو شكوى | ياخذ الاسم ورقم الوحدة والتفاصيل، ويحدد القسم (صيانة، إدارة أملاك، محاسبة...) ودرجة الاستعجال، ويسجّل تذكرة ويعطي العميل رقمها. |
| يسأل عن طلب سابق | يشوف تذاكره وحالتها وملاحظة الموظف. |
| طوارئ (غاز، حريق، تماس) | يطلب منه يبعد عن الخطر ويتصل على 998، ويسجّل تذكرة «طارئ»، ويحوّل المحادثة لموظف. |
| زعلان، أو يبي موظف، أو الموضوع فيه خلاف مالي أو قانوني | يحوّله لموظف ويسكت. الموظف يرد من اللوحة، وبعدها يرجّع المحادثة للوكيل. |

**وش ما يسويه:** ما يخترع أسعار ولا وحدات، وما يأكد حجز، وما يعطي مواعيد صيانة، وما يكشف بيانات عميل لعميل ثاني. أي معلومة ناقصة يقول «بتأكد لك من الموظف».

## لوحة الموظفين

افتح `https://عنوان-السيرفر/admin?token=ADMIN_TOKEN` من الجوال أو الكمبيوتر:
- كل التذاكر، وتقدر تفلترها حسب القسم والحالة.
- تغيّر حالة التذكرة (جديدة ← قيد المعالجة ← مغلقة)، وتكتب ملاحظة يقرأها الوكيل للعميل لما يسأل.
- المحادثات المحوّلة لموظف: ترد على العميل من اللوحة، وبعدها تضغط «رجّع المحادثة للوكيل».

## التشغيل خطوة بخطوة

### 1) عبّي معلومات الشركة
افتح `knowledge/policies.md` وعبّي كل سطر فيه ⟨للتعبئة⟩: أوقات الدوام، العنوان، العمولة، المستندات المطلوبة، العربون والمعاينة... الوكيل ما يجاوب على أي شي ناقص منها.

### 2) حوّل كشف الإكسل
```bash
pip install -r requirements.txt
python import_excel.py "عقارات للإيجار جديد.xlsx"
```
يقرأ كل الأوراق (سكني، تجاري، إداري، هلاديل...) ويطلع `data/units.json`. شغّله كل ما يتغير الكشف، والوكيل يقرأ النسخة الجديدة بدون إعادة تشغيل.
- تبي تستبعد ورقة؟ أضف `--skip "عقارات خارجية محدث"`.
- **انتبه:** أي ملاحظة مكتوبة فوق الجدول في الإكسل (مثل «رسوم حارس 50 ريال») تنضاف لوصف الوحدات، والوكيل يقولها للعملاء.
- ملف `units.json` وقاعدة البيانات **ما ينرفعون على GitHub** (موجودين في `.gitignore`) عشان بيانات العملاء والأسعار تبقى عندكم.

### 3) جرّب الوكيل من الطرفية قبل الواتساب
```bash
cp .env.example .env      # وحط ANTHROPIC_API_KEY
python chat_cli.py
```
اكتب كأنك عميل: «ابي شقة غرفتين بالروضة»، «المكيف خربان في شقتي»، «ابي اكلم موظف»...

### 4) جهّز رقم الواتساب (WhatsApp Cloud API من Meta)
1. في [Meta Business](https://business.facebook.com) سوّ حساب أعمال لأطوار ووثّقه.
2. في [developers.facebook.com](https://developers.facebook.com) سوّ تطبيق من نوع Business، وأضف له منتج WhatsApp.
3. أضف رقم قسم التأجير. **الرقم الأرضي ينفع**: التحقق يكون بمكالمة صوتية.
   - إذا الرقم شغّال حاليًا على تطبيق «واتساب للأعمال»، لازم تنقله للـ API. أو استخدم ميزة «التشغيل المشترك» (Coexistence) إذا كانت متاحة لكم، وتخليكم تستخدمون التطبيق والـ API مع بعض. تأكد منها في إعدادات Meta قبل النقل.
4. سوّ **توكن دائم** (System User Token) فيه صلاحية `whatsapp_business_messaging`.
5. انسخ للملف `.env`: التوكن، و Phone Number ID، و App Secret، واختر كلمة سر لـ `WHATSAPP_VERIFY_TOKEN`.

### 5) شغّل السيرفر
لازم سيرفر عليه HTTPS. الأفضل يكون داخل المملكة عشان نظام حماية البيانات الشخصية.
```bash
uvicorn agent.server:app --host 0.0.0.0 --port 8000
```
بعدها في إعدادات WhatsApp عند Meta، قسم Configuration ← Webhook:
- **Callback URL:** `https://عنوان-السيرفر/webhook`
- **Verify token:** نفس قيمة `WHATSAPP_VERIFY_TOKEN`
- اشترك في حقل **messages**.

### 6) أرسل رسالة للرقم من جوالك وجرّب 🎉

## التكلفة التقريبية
- **Claude:** النموذج `claude-opus-5-5` بمستوى تفكير `low`. التكلفة تقريبًا أقل من ريال للمحادثة الكاملة (عدة رسائل)، وتختلف حسب طول المحادثة. القواعد الثابتة تتخزن مؤقتًا (prompt caching) عشان تقل التكلفة.
- **Meta:** الردود على رسائل العملاء خلال 24 ساعة من آخر رسالة لهم ما عليها رسوم حسب أسعار Meta الحالية. أما الرسائل اللي تبدأها الشركة (حملات، تذكيرات) فلها رسوم. تأكد من صفحة الأسعار عند Meta.

## هيكل الملفات
```
agent/
  core.py       حلقة الوكيل: رسالة العميل ← Claude ← الأدوات ← الرد
  prompt.py     قواعد الوكيل وأسلوبه
  tools.py      الأدوات: البحث في الوحدات، تسجيل تذكرة، تذاكري، التحويل لموظف
  units.py      البحث في الوحدات الشاغرة
  store.py      قاعدة البيانات (المحادثات والتذاكر)
  whatsapp.py   استقبال وإرسال رسائل الواتساب
  server.py     السيرفر ولوحة الموظفين
knowledge/policies.md   معلومات الشركة وسياساتها (عبّها!)
import_excel.py         تحويل كشف الإكسل
chat_cli.py             تجربة من الطرفية
tests/                  اختبارات (python -m pytest)
```

## الخطوات الجاية
- قراءة الرسائل الصوتية والصور (اليوم يرد على النص بس، ويقول للعميل يكتب).
- إشعار للقسم المختص على الواتساب أو الإيميل لما تنفتح تذكرة «طارئ».
- ربطه مع منصة أطوار و«أملاكي» بدال الإكسل.
- العقد الإلكتروني السريع: يجمع بيانات العقد من العميل ويجهزها للموظف.
